📌 How to sync with Slack Canvas
1. Select a client and month above
2. Click 🌐 Copy Rich HTML — then paste directly into a Slack Canvas for a formatted table with bold headers
3. Or use 📋 Copy Plain Text for a plain mrkdwn version you can paste anywhere in Slack
4. In Slack: open the client channel → click Canvas at the top → paste

⚠️ Rich HTML note: Slack Canvas accepts pasted HTML in most desktop browsers (Chrome/Edge). If it pastes as raw code, use Plain Text instead.

💡 Automate it: Use Zapier or Make.com with the Slack API to push updates automatically.
